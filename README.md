# BlackBearReloaded's PS5 projects

Static personal site for [blackbearreloaded.github.io](https://blackbearreloaded.github.io).

Edit `index.html` for project content and `style.css` for appearance. GitHub Pages publishes the `main` branch from the repository root. No build step is needed.
